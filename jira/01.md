# Practical 1: Team Creation and Role Assignment in Jira

## Aim

To create a team in Jira, add team members, and assign appropriate roles to them.

## A. Add Team Members

Procedure:

1. Open [Jira Cloud](https://www.atlassian.com/software/jira) and sign in.
2. Open your existing project.
3. For a company-managed project, go to Project settings → People.
4. For a team-managed project, open the three-dot menu → Space settings → Access.
5. Click Add people.
6. Enter the name or email address of the team member.
7. Select the required role from the dropdown menu.
8. Click Add to add the team member.&#x20;

## B. Assign Roles

Procedure:

1. Open Project settings → People or Space settings → Access, depending on your project type.
2. Locate the team member in the list.
3. Select the role dropdown or role assignment option.
4. Assign the appropriate role:

| Role          | Responsibility                      |
| ------------- | ----------------------------------- |
| Administrator | Manages project settings and access |
| Member        | Creates, edits and manages issues   |
| Viewer        | Views project information           |

5. Save the changes if prompted.
6. Verify that the team member appears with the assigned role.

Note: Available roles and permissions depend on the project type and Jira configuration
