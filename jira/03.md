Practical 2: Issue Types and Configuration in Jira
Aim
To create and configure Epic, Story, Task and Bug issue types, and create Components and Versions in Jira.
A. Create and Configure Issue Types
Procedure:
1. Open Jira Cloud and sign in.
2. Open your Jira project.
3. Navigate to Project settings → Issue types (may appear as Work types in the updated interface).
4. Check whether Epic, Story, Task and Bug already exist.
5. If any issue type is missing, open Settings → Work items → Work types → Add work type.
6. Enter the issue type name and description, select the appropriate type, and click Add.
7. Open Work type schemes and add the required types to the scheme associated with your project, if necessary.
8. Create or verify the following issue types:
Issue Type	Purpose
Epic	Groups a large task or feature
Story	Represents a user requirement
Task	Represents work to be completed
Bug	Records an error or defect

9. Save the configuration and verify that all four types are available when creating issues.

Reference: Atlassian — Configure issue types.

B. Create Components and Versions
1. Create Components
Procedure:
1. Open your Jira project.
2. Open More actions (•••) → Project settings.
3. Select Components.
4. Click Create component.
5. Enter the component name Frontend.
6. Enter a description and select a component lead if required.
7. Click Save.
8. Repeat the process to create a component named Backend.
9. Verify that both components appear in the component list.
Reference: Atlassian — Configure Jira components. 

Atlassian Support



2. Create Versions
Procedure:
1. Open your Jira project.
2. Navigate to Releases or Project settings → Versions.
3. Click Create version.
4. Enter the version name 1.0.0.
5. Add a start date and release date if required.
6. Enter a description such as Initial release.
7. Click Save.
8. Verify that version 1.0.0 appears in the versions list.
Reference: Atlassian — Enable releases and versions.
