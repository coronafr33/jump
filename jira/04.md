Practical: Issue Management in Jira
Aim
To create issues under an Epic in Jira, assign issues to users, and set their Priority and Due Date.
A. Create Issues Under an Epic
Procedure:
1. Open Jira Cloud and sign in.
2. Open your Jira project.
3. Navigate to Backlog or Roadmap.
4. Create a new Epic named Website Development.
5. Open the Epic and note its name or issue key.
6. Create a Story named Design Homepage.
7. Create another Task named Develop Login Page.
8. Create a Bug named Login Error.
9. For each issue, select the Epic as its Parent or use the Epic Link field if your Jira interface uses it.
10. Click Create or save the issue.
11. Verify that all issues are linked to the Website Development Epic.

B. Assign Issues to Users and Set Priority and Due Date
Procedure:
1. Open the issue, such as Design Homepage.
2. Click Assignee and select a team member.
3. Click Priority and select High.
4. Click Edit if the Due Date field is not directly visible.
5. Enter a due date, for example, 30/10/2026, using the date format accepted by Jira.
6. Click Update or save the issue.
7. Repeat these steps for the remaining issues, selecting suitable assignees, priorities, and due dates.
8. Open each issue and verify that the details have been saved.

Result
Issues were created and linked to the Website Development Epic. The issues were assigned to team members, and their priorities and due dates were configured successfully.
