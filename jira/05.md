Practical: Workflow Customization in Jira
Aim
To design a custom workflow in Jira and add transitions and conditions.
A. Design a Custom Workflow
Procedure:
1. Open Jira Cloud and sign in.
2. Open your Jira project.
3. For a company-managed project, go to Settings → Work items → Workflows. For a team-managed project, go to Project settings → Work types and select a work type.
4. Click Add workflow or Edit workflow, depending on the project type.
5. Enter the workflow name as Student Task Workflow.
6. Add the following statuses:
   - To Do
   - In Progress
   - In Review
   - Done
7. Arrange the statuses in the required order.

B. Add Transitions and Conditions
Procedure:
1. Open the workflow editor.
2. Click Add transition.
3. Set the From status as To Do and the To status as In Progress.
4. Enter the transition name Start Progress and save it.
5. Similarly, create transitions from In Progress to In Review and from In Review to Done.
6. Select the transition where you want to apply a condition.
7. In the transition details, open Rules or Conditions and click Add.
8. Select an available restriction, such as allowing only users with a specified project role to perform the transition.
9. Configure the condition and save it.
10. Publish or update the workflow.
11. Open an issue and test whether the transitions work as expected. 
    
    
Result
A custom Jira workflow named Student Task Workflow was designed successfully, and transitions and conditions were configured to control the movement of issues between statuses.
